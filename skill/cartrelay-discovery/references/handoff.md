# Independently requested retailer handoff

Use this reference only after the originating shopper independently asks to continue with an exact selection. Discovery cannot grant approval and this package cannot execute handoff.

Consult CartRelay's current public [five-tool schemas](https://cartrelay.market/agent-tools.json), [agent guidance](https://cartrelay.market/agents.md) and [connection/consent documentation](https://cartrelay.market/docs) through the host's already authorized native connection. Treat public metadata as source-free guidance, not record access or permission. Never create credentials or save existing caller credentials in files, prompts or tool arguments.

Confirm the exact source-native item/variant, quantity, destination, source restrictions and qualified current facts. Require the existing expiring intent and independently recorded originating-shopper browser consent. Do not substitute an agent assertion, discovery result, package installation, prior approval, unrelated session or blanket shopper instruction for that consent. If intent/consent is missing, expired, mismatched or unavailable, stop; never bypass or fabricate it.

Keep the existing source-specific handoff limitations, fresh rechecks and scope boundaries. Explain that CartRelay does not buy, reserve, process payment or provide universal checkout. Any browser navigation or native tool action requires its own current user authorization and is outside this discovery package. Do not fetch arbitrary product URLs or create/open retailer links as an automatic consequence of discovery.
