# Package provenance and framework compatibility

The runtime `lib/cartrelay-discovery.mjs` is a byte-for-byte copy of CartRelay's explicitly approved released public client, `public/examples/cartrelay-discovery.mjs`, available at https://cartrelay.market/examples/cartrelay-discovery.mjs. Its reviewed SHA-256 is `6966ef7ea6ab950b309520c73871e2edb5b28f63b1b36b0d2c0d846453881ee6`. The reference contract and safety guidance is the approved repository document `docs/catalogue-discovery.md`; public connection/consent guidance is https://cartrelay.market/docs. No server implementation, private discovery kit, source assets, catalogue records or credentials are included.

Verified 2026-11-15: LangChain `@langchain/core@1.4.1` exposes `tool(function, {name,description,schema})` and validates JSON Schema. The adapter retains that genuine framework tool and schema, but replaces its execution methods to avoid framework parsing exceptions retaining raw input and automatic tool tracing. Only its approved client transport executes. Parent agents can still retain inputs/results; the host must disable those traces and avoid raw data retention. Official references: [tool API](https://reference.langchain.com/javascript/langchain-core/tools/tool), [tools module](https://reference.langchain.com/javascript/langchain-core/tools), [official implementation](https://github.com/langchain-ai/langchainjs/blob/9d87ca1a5548bc23bb091016870c76ddd60e127c/libs/langchain-core/src/tools/index.ts).

Verified 2026-11-15: LlamaIndex's official TypeScript documentation retains `FunctionTool` and the `tool` alias. `FunctionTool.from(function, {name,description,parameters:jsonSchema})` is exposed by the minimal `@llamaindex/core/tools` subpath. Its plain JSON Schema path does not validate arguments; the adapter validates them in the safe function before credential access, avoiding the framework's Zod warning/logger path. Official references: [tools documentation](https://developers.llamaindex.ai/typescript/framework/modules/agents/tool/), [official FunctionTool implementation](https://github.com/run-llama/LlamaIndexTS/blob/main/packages/core/src/tools/function-tool.ts).

The registry's latest minimal `@llamaindex/core@0.6.23` is marked deprecated and no longer maintained, as is its `@llamaindex/env` dependency. This adapter is tested against that exact published version only; it is not a promise of ongoing LlamaIndex maintenance. The umbrella `llamaindex@0.12.1` currently depends on core 0.6.22, not 0.6.23; installing only the umbrella package does not satisfy this adapter's explicit peer. Neither the umbrella nor any model/provider package is necessary here. Review the deprecation before publishing or selecting it for a maintained application.
